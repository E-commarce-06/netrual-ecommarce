# Nike: UX analysis

**Evidence basis:** screenshots 01–15 (viewed: home phone 390). DOM facts from `facts.json`.

## 1. Minimal header, icon-only actions
- The mobile header has four icons: search, account, bag (with item count in its label), and menu. There is no visible text except the logo.
- **Why:** the brand is the product, so the chrome stays quiet. Icons keep the header short, which gives the hero the space. The bag count is read by screen readers, which makes it accessible even without a label.

## 2. Full-bleed hero with one headline, one subline, one CTA
- The first screen is a single photo, a bold headline ("Fully invested"), one line of support copy, and one pill button ("Shop NFL").
- **Why:** one primary action reduces choice (Hick's law). The button is in the lower-left, where the eye lands after the headline.

## 3. Persistent app-install banner at the bottom
- A fixed bar at the bottom shows "Only in the Nike App" with an "Open" button and a dismiss "×".
- **Why:** app installs carry member benefits (access, rewards). A bottom bar stays in the thumb zone, but the dismiss control keeps it from feeling trapped.

## 4. Search is an icon, not a field
- The search icon is in the header on mobile, and the desktop field is labelled "Search Products".
- **Why:** on a brand-led site, search is a secondary action, so it does not need permanent space. The trade-off is that shoppers who know the product name must tap first.

## Lessons for a re-skin
- Use one hero message and one CTA per screen.
- Keep the header to icons with accessible names.
- A dismissible bottom banner can carry an app or membership offer.

## What not to copy
- Icon-only search hides the most useful entry point from first-time visitors. Keep a visible field on a catalogue-heavy site.
