# Target: UX analysis

**Evidence basis:** DOM facts from `facts.json`. Screenshots are clean but were not reviewed closely for this draft. No product page was captured on this run.

## 1. Location before products
- "Ship to 97058" with a store name ("Fairview") sits above the search bar.
- **Why:** pickup and delivery availability depend on the store. Showing it first avoids a dead end at checkout.

## 2. Search that asks a question
- The search placeholder reads "What can we help you find?", with "search by voice" and suggestions below.
- **Why:** a question-style prompt invites natural-language queries. Voice and suggestions reduce typing.

## 3. Sign-in with account creation
- "Sign in or create account" is one control.
- **Why:** combining the two reduces the number of choices for a new visitor.

## Lessons for a re-skin
- Put the delivery or store context above search.
- Use a conversational placeholder and show suggestions as the user types.

## What not to copy
- Without a product page capture, this analysis cannot judge the product-detail layout. Capture it before using Target as a reference for product pages.
